# The Walk-In — installable version

This folder is a complete, self-contained web app. No build step, no dependencies to install — it just needs to live at a real web address so your phone can install it.

## Get it online (GitHub Pages, free, ~10 minutes, one time)

1. Go to github.com and create a free account if you don't have one.
2. Click the **+** in the top right → **New repository**. Name it something like `walk-in-app`. Keep it Public. Create it.
3. On the new repo's page, click **Add file → Upload files**.
4. Drag in *every file and folder from this download* (`index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`, and the whole `icons` folder) and commit.
5. Go to the repo's **Settings → Pages**. Under "Branch," choose `main` and `/ (root)`, then Save.
6. Wait about a minute, then refresh — GitHub shows your live URL at the top, something like:
   `https://yourusername.github.io/walk-in-app/`

## Install it on your phone

1. Open that URL in Safari (iPhone) or Chrome (Android).
2. **iPhone:** tap the Share icon → **Add to Home Screen**.
   **Android:** tap the **⋮** menu → **Install app** (or you'll see an install banner automatically).
3. Open it from the home screen icon — full screen, no browser bar, works offline.

## Your data

Everything you check off or plan is saved in your phone's browser storage, on your device only. To back it up or move it to another device, use the **download icon** in the app header (Export) to save a `.json` file, and the **upload icon** (Import) to restore it.
